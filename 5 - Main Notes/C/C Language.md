# C Language — History & Overview

## History
C was born out of the need for a practical programming language. Before C, only Assembly was widely used. C is a *medium-level* language — human-readable enough for developers, yet abstract enough for computers to handle efficiently.

C made Unix **portable**, replacing Assembly as the primary systems language.

| Year | Event |
|---|---|
| 1970s | Dennis Ritchie & Ken Thompson develop C at Bell Labs |
| 1980s | ANSI standardizes C (ANSI C) |
| 1989 | ISO adopts the standard (C89/C90) |

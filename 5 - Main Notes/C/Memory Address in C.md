# Memory Address in C

When a variable is created in C, a **memory address** is assigned to it. The memory address is the location where the variable is stored in RAM.

When we assign a value to a variable, it is stored at that memory address. To access the address, use the **reference operator** (`&`):

![[_assets/Pasted image 20260131151954.png]]

`&num` is often called a **"pointer"** — it stores the memory address of a variable as its value. To print pointer values, use the `%p` format specifier.

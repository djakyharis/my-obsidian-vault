# Algorithm

## 📝 Notes

Algorithm adalah a set of steps to accomplish a task.

Dalam computer science, algoritma adalah set of steps untuk program komputer menyelesaikan tugas.

### Implementasi Algoritma pada Sistem
- **Google Hangouts**: Audio dan Video compression algorithm
- **Google Maps**: Route finding algorithm
- **3D Graphics**: Rendering Algorithm

### What Makes a Good Algorithm?
1. **Correctness** — Solves the problem it's designed to solve
2. **Efficiency** — Uses minimal time and resources to do so

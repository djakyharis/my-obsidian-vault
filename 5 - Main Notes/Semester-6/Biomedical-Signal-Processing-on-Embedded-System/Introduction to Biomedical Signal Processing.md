# Introduction to Biomedical Signal Processing on Embedded Systems

## What is Biomedical Signal Processing?
The acquisition, analysis, and interpretation of signals generated by the human body — for the purpose of understanding physiological states or diagnosing medical conditions. When done on **embedded systems**, this means real-time processing with constrained resources (limited RAM, CPU, power).

## Signal Pipeline (General)
```
[Body] → Sensor → Analog Signal → ADC → Embedded Processor → Analysis → Output
```

## Key Signals Studied
| Signal | Source | Sensor | Use |
|---|---|---|---|
| **ECG** (Electrocardiogram) | Heart electrical activity | Electrodes | Arrhythmia, HRV |
| **PPG** (Photoplethysmography) | Blood volume pulse | Optical (e.g. MAX30105) | Heart rate, SpO2, HRV |
| **EMG** (Electromyography) | Muscle electrical activity | Electrodes | Prosthetics, fatigue |
| **EEG** (Electroencephalogram) | Brain electrical activity | Electrodes | Sleep, seizure |

## HRV — Heart Rate Variability
HRV is the variation in time between consecutive heartbeats (R-R intervals). It is a key indicator of autonomic nervous system activity and **stress levels**.

### HRV Metrics
| Metric | Full Name | What it measures |
|---|---|---|
| **RMSSD** | Root Mean Square of Successive Differences | Short-term HRV, parasympathetic activity |
| **SDNN** | Standard Deviation of NN intervals | Overall HRV, autonomic balance |
| **BPM** | Beats Per Minute | Heart rate |

## Embedded Implementation — StressPredictor Project
This course connects directly to the real project:
- **Sensor**: MAX30105 (optical PPG sensor)
- **MCU**: Arduino/ESP32
- **Pipeline**: PPG → beat detection → RR intervals → RMSSD/SDNN/BPM → Random Forest model → Stress classification
- **Library**: `StressPredictor` (custom Arduino library)

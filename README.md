# My Obsidian Vault

Personal knowledge base using Obsidian. Notes are organized using a pipeline system inspired by Zettelkasten.

## Folder Structure

| Folder | Purpose |
|---|---|
| `1 - Rough Notes/` | Quick capture — raw ideas, course notes, temporary staging |
| `2 - Source Material/` | Notes taken directly from a specific source (book, course, video) |
| `4 - Templates/` | Blank templates for creating new notes |
| `5 - Main Notes/` | Permanent, processed knowledge — the real second brain |
| `6 - MOC/` | Maps of Content — index notes that connect related notes |
| `_assets/` | All images and attachments |

## Note Pipeline

```
Capture (Rough Notes) → Process → Graduate (Main Notes) → Link → MOC
```

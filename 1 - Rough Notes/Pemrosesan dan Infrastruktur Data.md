# Data Engineer
Sebagai Data Engineer kita bisa memprediksi dan mempersiapkan sebelum terjadinya kejadian yang mau diprediksi, juga harus mencari tahu bagaimana bisa mendapatkan data-data dengan sesuatu yang berkorelasi.

Cara mengambil data:
- Sensor
- Database

#### Data Processing
Konversi "Raw data" menjadi informasi yang berarti.

#### Data Infrastructure
Beberapa set dari teknologi, proses, dan resources yang mendukung bagaimana data diperoleh (collection), bagaimana data disimpan (storage), dan bagaimana data diolah untuk menghasilkan wawasan (analysis).
